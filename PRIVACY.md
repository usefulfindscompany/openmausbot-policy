# Privacy Policy for OpenMausBot Integration

This application runs entirely as a local, private automation tool on the user's local machine. 

## Data Collection & Storage
- **No External Tracking:** No user data, profile metrics, or video files are collected, tracked, or transmitted to any external servers.
- **Local Storage:** All TikTok API tokens, account access information, and session data remain securely stored on your local disk within the local runtime directory.
- **Third-Party Data:** The app connects to the TikTok API solely to manage, schedule, and draft content directly from your personal desktop. No data is sold or shared with third parties.
